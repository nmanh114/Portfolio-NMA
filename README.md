## 📁 CASE FILE

**Subject:** Nguyễn Minh Ánh
**Field:** International Economics
**Institution:** Foreign Trade University — FTU
**Cohort:** 2025–2029

This repository contains my personal portfolio website, designed as a **forensic investigation file** rather than a conventional résumé.

The website turns different parts of my academic journey, experiences, skills, and achievements into pieces of evidence within one interactive case.

---

## 🔍 THE INVESTIGATION

> **What happens when a portfolio becomes a case file?**

Instead of presenting information as a simple list, the website uses a detective-inspired visual language to guide visitors through my background.

Each section represents another part of the investigation:

| FILE                | CONTENT                                              |
| ------------------- | ---------------------------------------------------- |
| 🪪 **PROFILE**      | Personal introduction and background                 |
| 🎓 **EDUCATION**    | Academic journey and university experience           |
| 🏆 **ACHIEVEMENTS** | Academic milestones and accomplishments              |
| 💼 **EXPERIENCE**   | Relevant experiences and activities                  |
| 🧠 **SKILLS**       | Technical, analytical, language and practical skills |
| 📜 **EVIDENCE**     | Certificates and supporting documents                |
| 📂 **PROJECTS**     | Selected work and activities                         |

## 🧬 SUBJECT PROFILE

I am interested in **numbers, logical thinking, and problem-solving**.

## 🕵️ DESIGN & CONCEPT

### `FORENSIC INVESTIGATION`

The visual identity of the portfolio is inspired by:

* 🔎 Detective investigations
* 📁 Classified case files
* 🧾 Evidence documents
* 🧩 Clues and connections
* 🖥️ Digital investigation interfaces

The goal is to make exploring a résumé feel more like **opening a case file and investigating a person’s journey**.
